# ローカルへの引き継ぎ手順

この運用では Claude が GitHub Actions 上で動くため、**画像・音声の作成**と
**実際に遊んでの手触り確認**は人間にしかできない。ここが漏れると PR が
そのまま止まるので、引き継ぎは PR 本文の必須項目として書く。

`.github/pull_request_template.md` の該当セクションを埋めること。

## ローカル作業依頼

必要なものが**一目で分かり、そのまま作業に入れる**粒度で書く。

```markdown
## ローカル作業依頼

- `art/enemies/slime.png` を作成して配置
  - 16x16 / PNG / 透過あり
  - 配置先: `res://art/enemies/`
  - 用途: Slime の Sprite2D テクスチャ（scenes/enemies/slime.tscn が参照）
- 配置後、Godot エディタで一度開いて `.import` を生成し、コミットしてください
```

書き方の決まり:

- **ファイル名・寸法・形式・配置先パス**を必ず書く（「敵の画像」だけでは足りない）
- どのシーン / スクリプトがそれを参照するのかを添える
- `.import` の生成が必要な場合はその旨を明記する
- **依頼が無い場合は「なし」と書く。** 空欄のまま出さない

## 動作確認手順

「何をどう確認すれば完了と言えるか」を、再現できる手順で書く。

```markdown
## 動作確認手順

1. `git pull` 後、Godot エディタで `scenes/main.tscn` を開く
2. F5 で実行
3. 敵に接触すると HP バーが減り、0 で game_over.tscn に切り替わることを確認
4. 手触りの観点: 無敵時間 0.5 秒が短すぎないか。長くしたい場合は
   `resources/player/player_stats.tres` の `invincible_time` を調整してください
```

書き方の決まり:

- CI で担保済みのこと（テストが通る等）は書かない。**人間の目でしか分からないこと**を書く
- 調整可能なパラメータがある場合は、どのファイルのどの値かを示す
- 手触りの評価が必要なら、何を基準に見てほしいのかを書く

## 最後に

CI がグリーンでも、この 2 セクションが埋まっていない PR は未完成として扱う。
`CLAUDE.md` の「完了の定義」に含まれている。
